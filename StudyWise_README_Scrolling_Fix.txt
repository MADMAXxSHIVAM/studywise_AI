STUDYWISE AI — SCROLLING VERSION

Files in the complete bundle:
- StudyWise_AI_Scrolling_Fix.py: the updated desktop application.
- StudyWise_AI_Project_Report_Updated.pdf: the project report.

Requirements (Linux Mint / Ubuntu):
1. Open Terminal.
2. Run:
   sudo apt update
   sudo apt install python3 python3-tk
3. Extract the ZIP file into a folder.
4. Open Terminal in that folder and run:
   python3 StudyWise_AI_Scrolling_Fix.py

Scrolling:
- Use the mouse wheel over the main page to move through the whole form.
- Use the table's vertical scrollbar to browse a long topic list.
- Use the table's horizontal scrollbar if all columns do not fit.

Adding a topic:
- Fill in the subject, topic/chapter, days left, difficulty, confidence,
  exam importance, and available study time.
- Scroll down inside the left-hand form if necessary.
- Click ADD TOPIC & ANALYSE to add the topic to the revision table.

Your saved topic data is stored locally in studywise_data.json in the
same folder where the application is run. Keep this file if you want to
preserve your saved topics when replacing the Python script.
